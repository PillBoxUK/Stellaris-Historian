STELLARIS HISTORIAN v0.0.74 — GALACTIC OBSERVATORY

CONTENTS: A flat-root source-code-only classic patch.
No wrapper directory, payload installer or changes to your existing archives.

- New regression tests; no parser, save watcher, SQLite schema or migrations modified.

INSTALL (EXISTING CLASSIC PROCESS)
1. Turn Live History OFF and wait for processing to stop; close Historian.
2. Back up any pre-existing app files named in SHA256SUMS_v0.0.74.txt.
3. Copy these extracted files and folders to G:\codex\StellarisHistorian,
   preserving the structure and overwriting files with matching names.
4. Start with the original G:\codex\StellarisHistorian\start.bat.
5. Check version 0.0.74 on the dashboard and open Historical Observatory.

No reset/rebuild/review of campaign history is needed. A restart IS required.
Nothing is committed or pushed to GitHub by this package.

PROTECTED / EXCLUDED
No data, *.sav, *.db, *.sqlite, *.sqlite3, logs, private config,
autobackups, forensic caches, .venv, or user-owned files in the ZIP.

TESTED: Python compilation, v66–v74 regression tests, Chromium interactions,
HTML escaping, political-state date provenance, and isolated PDF generation.
Full real-world Commonwealth data remains to be checked on the user's PC.
