# Migration Notes - v0.0.41

## Scope

v0.0.41 is a presentation-architecture release. It rebuilds the Empire Timeline and Scribes combat chapter on the shared Historical Event Layer and synthesized combat episodes.

## Automatic startup validation

On first startup, `migrate_v0_0_41.py` validates the required v0.0.41 source files and byte-compiles the presentation/event modules. It writes:

- marker: `data/.migration_v0_0_41_complete`
- log: `logs/MIGRATION_v0.0.41.log`

No database rows, campaign paths, archive saves, cache component versions or processed flags are migrated.

## Required user action

After installing the patch:

1. Restart Stellaris Historian.
2. Run **Review Campaign** once.

The review refreshes `Historical_Event_Debug.txt` using the expanded v0.0.41 Historical Event attributes. Existing domain evidence remains reusable, so a Construct Campaign reset is not required.

## Data compatibility

Cache component versions remain unchanged:

- People: v4
- Ships: v2
- Worlds: v2
- Science: v1
- Combat: v3
- Technology: v1

The v0.0.40.1 per-fleet retained combat-state fix remains in place. v0.0.41 changes how that evidence is selected and narrated, not how archived saves are stored.

## Rollback note

Because there is no schema or cache migration, rolling back code to v0.0.40.1 does not require restoring the database or archived saves. Any v0.0.41-generated presentation/debug output can simply be regenerated by the version in use.
