Stellaris Historian v0.0.71 - Research Date Integrity & Evidence Audit

CLASSIC FLAT PATCH: same structure as v0.0.70 and previous patch ZIPs.
Files and folders in this ZIP are relative to the HISTORIAN INSTALL ROOT.
Do NOT extract or install into StellarisHistorian_GitHubMerge.

INSTALLATION
1. In Historian, wait for history processing to finish, turn Live History OFF, and close Historian fully.
2. Back up the existing files you are going to replace (or use your established autobackups workflow).
3. Extract this ZIP into G:\codex\StellarisHistorian and allow matching files to be replaced.
   If you extract it to a staging folder first, copy the contents (not the staging folder)
   into G:\codex\StellarisHistorian, keeping the same historian/, docs/, static/ paths.
4. Start Historian with G:\codex\StellarisHistorian\start.bat.
5. Verify app version 0.0.71 and the War Journal Research Evidence Audit.
