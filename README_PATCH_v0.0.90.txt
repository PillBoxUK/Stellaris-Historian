SAFE INSTALL
1. Turn Live History OFF, wait for processing, close Historian.
2. Back up your installation AND SQLite/archive separately.
3. Unzip directly into G:\codex\StellarisHistorian\, overwriting matching source files.
   Do not create a nested folder and do not delete your data directory.
4. Run start.bat; verify the version shows v0.0.90.
5. Choose YES to Live History for the selected campaign; confirm ON.
6. Open the Imperial Annals. Test the reading-level selector and HTML export.
