STELLARIS HISTORIAN - AUTO BACKUPS EXPORTER UPDATE

Copy Export_Historian_Source.bat and Export_Historian_Source.ps1
into your existing G:\codex\StellarisHistorian directory,
replacing the previous exporter files.

Double-click Export_Historian_Source.bat.

Your source archives now go to:
G:\codex\StellarisHistorian\autobackups\Historian_Source_YYYYMMDD_HHMMSS.zip

The autobackups directory is created automatically.
No saves, databases, virtual environments, logs or backup archives are included.
This utility changes only the export destination, not Historian's application code.
It is not a full application/database backup.

Application restart required: NO.
